The Last Match — a tiny ancient matchbox on polished black obsidian opens, and a gigantic celestial phoenix of molten solar plasma is born from it, rising in a spiral with a miniature galaxy glowing in its chest. The program (main.py, Python 3 standard library only) validates that the bundled entry.png is a whole PNG or JPEG image and copies it byte-for-byte to the output directory, verifying size and SHA-256 after the copy.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
